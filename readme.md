# Horários de Ônibus

# Descrição

Este site disponibiliza, de forma simples e prática, os horários de alguns ônibus da minha cidade. Além das tabelas de horários, o site também informa o próximo horário de saída do ônibus, tanto no sentido bairro → centro quanto centro → bairro.

# Objetivo

Criei este site com o objetivo de estudar desenvolvimento web e, ao mesmo tempo, contribuir com os moradores da cidade, especialmente os do meu bairro, facilitando o acesso aos horários dos ônibus.

# Funcionalidades

* Consulta dos horários de saída e chegada de alguns ônibus;
* Consulta do próximo horário disponível com base no horário atual do dispositivo;
* Navegação por meio de botões e tabelas simples e intuitivas.

## Tecnologias

* HTML: estrutura e conteúdo das páginas;
* CSS: estilização e layout;
* JavaScript: cálculo e exibição dos próximos horários.

# Atualizações

O projeto está finalizado e não possui desenvolvimento ativo. No entanto, os horários podem ser atualizados quando necessário, assim como novos ônibus podem ser adicionados ao site.
